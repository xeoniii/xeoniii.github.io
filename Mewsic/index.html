// architecture & features

Built for control.

No subscription models, no ads. Just a sleek, modern desktop audio experience you own.

Native Rust Audio Engine

High performance audio playback pipeline built in Rust. With built-in audio effects like Reverb, Bass-boost and more!

Mewsic Audio Engine V3

Elegant UI Design

A Clean and modern UI to make your listening experience even better. With support for custom accent colors and more coming soon!

React + Tauri

100% Offline*

Your audio files are stored and used locally, no cloud calls or subscriptions. *optional features like Usage tracking, track downloading, album art fetching and song lyric fetching requires an active internet connection.
